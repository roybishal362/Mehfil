# Security

## Reporting a problem

Please open a private security advisory on this repository (Security → Advisories → Report a
vulnerability) rather than a public issue.

## Threat model

| Threat                                 | What could go wrong                                                   | How Mehfil handles it                                                                                                                                                                                                                                                                                                                                                              | Evidence                                                                                                                                  |
| -------------------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Leaked AI key                          | Someone spends the Gemini quota                                       | The key exists only in the server's environment; the browser never sees it. CI scans every publishable file for key patterns and server-only variable names.                                                                                                                                                                                                                       | `scripts/check-secrets.mjs`, `src/server/config.ts`                                                                                       |
| AI endpoint abuse                      | Scripted calls drain the free tier                                    | Per-visitor token buckets (a full plan costs 4 of 24 tokens per 10 minutes), a per-model request budget under the free-tier limits, a response cache and, when Firebase is on, a required Firebase ID token verified against Google's public keys. Over-limit calls get `429` with `Retry-After`.                                                                                  | `src/server/app.ts`, `src/server/middleware/rate-limit.ts`, `src/server/middleware/auth.ts`, `src/server/app.test.ts`                     |
| Prompt injection                       | A description tells the model to ignore its instructions or leak data | User text is escaped and wrapped in `<user_input>` blocks that the instructions mark as data, never instructions. Answers must match a JSON schema, are validated with Zod, clamped and stripped of phone numbers, emails and links. The Copilot can only propose typed operations on existing IDs, and nothing changes until the user applies them.                               | `src/server/ai/prompts.ts`, `src/server/ai/tasks.ts`, `src/shared/schemas/operations.ts`, `src/server/app.test.ts` (hostile model output) |
| Invented facts                         | The model makes up vendors, phone numbers or prices                   | There are no schema fields for vendor names or contacts; real vendors are found through Google Maps links built by code. Money and dates are computed by the planning engine, never by the model: it returns bounded percentages and day offsets.                                                                                                                                  | `src/shared/domain/`, `src/shared/export/links.ts`                                                                                        |
| Cross-site scripting                   | Injected markup runs in the page                                      | React escapes all text; there is no `dangerouslySetInnerHTML`. A strict Content-Security-Policy allows scripts only from this origin (plus Google's sign-in script), no inline scripts or styles, and no `eval`. The prerendered page is checked for inline styles, and Zod runs without its `eval` fast path. Browser tests fail on any CSP violation.                            | `src/server/security/headers.ts`, `src/shared/zod.ts`, `src/client/prerender.test.tsx`, `e2e/support.ts`                                  |
| Reading someone else's plans           | One account reads or edits another's data                             | Firestore Security Rules allow `users/{uid}/plans` only to `uid` itself and validate every document's fields, types, size and server timestamp. Everything else is denied.                                                                                                                                                                                                         | `firestore.rules`, `tests/firestore.rules.test.ts`                                                                                        |
| Share-link leaks                       | A shared link exposes guests or contacts, or can be guessed           | Shared copies are built from a whitelist: no guest names, contacts, quotes or notes, and the result is re-validated against a strict schema. Link IDs are 128 random bits. Links expire after 90 days, cannot be listed, read the same when unknown or expired, and only their owner can update or delete them.                                                                    | `src/shared/export/share.ts`, `src/client/cloud/shares.ts`, `firestore.rules`                                                             |
| Lost or clashing edits                 | Two devices overwrite each other                                      | Every cloud save is a transaction that only succeeds over the revision the device last saw; otherwise the user chooses which version to keep. Revisions only increase.                                                                                                                                                                                                             | `src/client/cloud/sync.ts`, `src/client/cloud/reconcile.ts` and tests                                                                     |
| Spreadsheet formula injection          | An exported guest list runs formulas in Excel                         | CSV export prefixes cells that start with `=`, `+`, `-`, `@` or control characters.                                                                                                                                                                                                                                                                                                | `src/shared/export/csv.ts`                                                                                                                |
| Oversized or malformed requests        | Memory or parser abuse                                                | 32 KB body limit, JSON content type required, every body validated with Zod (bounded strings, arrays and numbers, unknown keys dropped). Errors return a stable code and a request ID, never stack traces.                                                                                                                                                                         | `src/server/routes/ai.ts`, `src/server/http.ts`, `src/server/errors.ts`                                                                   |
| Clickjacking and other browser attacks | The app is framed or downgraded                                       | `frame-ancestors 'none'` and `X-Frame-Options: DENY`, HSTS with preload, `nosniff`, a strict referrer policy, a restrictive Permissions-Policy and `Cross-Origin-Opener-Policy: same-origin-allow-popups` (for the Google sign-in window). The same policy is applied by the Node server and written into Vercel's routing.                                                        | `src/server/security/headers.ts`, `scripts/lib/vercel-output.ts`                                                                          |
| Logging personal data                  | Plans or prompts end up in logs                                       | Logs are structured JSON with request IDs, timings, models and cache hits only, never request bodies, prompts or guest data.                                                                                                                                                                                                                                                       | `src/server/middleware/request-context.ts`, `src/server/app.test.ts` (log privacy)                                                        |
| Supply chain                           | A compromised dependency                                              | Lockfile installs (`npm ci`), a production `npm audit` gate, Dependabot and CodeQL. When a fix has not reached a dependency yet, an npm override pins the patched version: `@grpc/grpc-js` 1.14.6 or later under Firebase (GHSA-m9gg-hp2v-232j, GHSA-f596-whhp-79r4). The server bundle has no runtime `node_modules`, and the container image is distroless and runs as non-root. | `.github/workflows/`, `Dockerfile`                                                                                                        |

## Data and privacy

- Plans are stored in the browser by default. Signing in with Google copies them to Cloud
  Firestore, readable only by that account.
- Guest names and contacts are never sent to the AI; only counts are.
- The free Gemini tier may use inputs to improve Google's products; the app tells users so and
  sends only the event details the plan needs.
- **Account → Delete my cloud data** removes synced plans, every share link and the account
  itself. **Delete all plans on this device** clears the browser's copy.
