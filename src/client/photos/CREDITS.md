## Sizes

Arch photos (4:5) come in 240, 480 and up to 720 pixels wide; a source smaller than that is
never enlarged, so the largest file name carries the real width (for example `ganpati-546`).
Moment photos are 16:10, up to 1280 pixels. Files stay under 150 KB each and 1.4 MB in all
(`scripts/photo-budget.test.ts`).
